# Design Doc of "Vampiire-Man"

*Core Loop*: Surviving a labyrinth by killing vampires and collecting upgrades

*Goal*: To survive as long as possible

*Challenge*: Enemies actively oppose the player, trying to follow the player to kill

*Feedback*: Players knows their killcount, level, high score

*Progress*: New weapons, bigger waves, upgrades to weapons


*Theme*: Vampires, Dracula, Arcade. Churhc

*Setting*: Church's basement

*What do you collect*: Upgrades and weapons
